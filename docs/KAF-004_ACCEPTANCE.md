| KAF4-AC-03 | 성인 1명, 왕복 일반석, KRW, 세금 포함, 대한항공 운항 직항 조건을 일관되게 적용한다. 공동운항편은 구분한다. | 검색 요청과 실제 예약 결과 비교 |
| KAF4-AC-04 | 금·토 출발과 다음 주 토·일 귀국 조합을 오늘부터 365일까지 생성한다. 제공자 예약 가능 범위 밖 날짜는 미제공으로 처리한다. | 날짜 생성 결과의 경계값·요일·조합 확인 |
| KAF4-AC-05 | 사용자가 정의한 특수 연휴 조건을 최대 5개 추가할 수 있고 평일·공휴일 기준 연차 참고값을 계산한다. | 특수 일정 입력 및 연차 계산 결과 확인 |
| KAF4-AC-06 | 단계 A에서 3개 목적지 × 한 주의 최대 4개 날짜 조합을 조회해 실제 반환 운임과 대한항공 예약 결과를 대조한다. | 각 검색 조건, 실제 결과, 비교 근거 기록 |
| KAF4-AC-07 | Amadeus Self-Service 등 운임 데이터 후보에서 KE 직항 운임의 실제 노선 커버리지, 프로덕션 호출 한도·비용, 반복 자동 조회 및 가격 저장 조건을 확인한다. 확인 전 비공개 API·스크래핑·차단 우회를 사용하지 않는다. | 제공자 공식 약관·공개 API 문서 또는 서면 근거 확인 및 세 목적지 표본 검색 |
| KAF4-AC-08 | 3개 목적지 전체 후보는 기본 최대 624개이며 7개 일일 배치로 순환한다. 실제 호출 한도에 맞지 않으면 실행 전에 규모를 보고한다. | 후보 수 계산 및 배치별 호출 로그 확인 |
| KAF4-AC-09 | 가격 관찰은 로컬에 저장하고 기존 행을 보존한다. 관찰 시각, 여행 조건, 출처, 총액, 운항·직항 정보, 조회 실패 상태를 저장한다. | 연속 실행 전후 저장 결과 비교 |
| KAF4-AC-10 | 미조회·미제공·오류를 0원 또는 예시 운임으로 채우지 않는다. 실제로 기록된 365일 관찰이 없으면 1년 최저·평균으로 표시하지 않는다. | 빈 결과·실패·초기 기록 상태 확인 |
| KAF4-AC-11 | 단계 A와 B 결과가 정확성·허용 범위·호출 한도 기준을 만족할 때만 전체 대한항공 직항 목적지로 확대한다. | 확대 조건과 시험 결과 대조 |
| KAF4-AC-12 | 실제 운임 자동 접근이 확인되지 않으면 자동 검색을 완료한 것처럼 표시하지 않고, 미검증 또는 보류로 명시한다. | 결과 표시와 인수 보고서 확인 |
