## 목표

KAF-001 시제품의 검색 행동을 간단히 하고, 예시 운임 목적지를 실제 지리 좌표에 맞춰 지도에 표시한다. 지도의 노선과 표식은 데모 검색 결과를 시각화하며, 실제 운항 가능 여부를 보장하지 않는다.

## 요구사항

1. 검색 실행 버튼의 표시 문구는 검색이다.
2. 손으로 그린 대륙 모양 대신 실제 지리 데이터를 사용하는 세계 지도를 표시한다.
3. 지도에 목적지 도시 중심점이 아니라 목적지 공항의 위도·경도를 사용한다. 공항 코드는 결과의 IATA 코드와 일치해야 한다.
4. 출발지와 목적지 사이에 직항 노선을 표시할 때는 현재 검색 결과의 direct 값이 참인 경우에만 노선을 그린다. 경유 결과를 직항으로 표현하지 않는다.
5. 결과 필터에 남은 목적지만 지도에 표시한다. 대한항공만 선택하면 대한항공 결과만 표시하고, 대한항공/SkyTeam 선택은 그 조건에 맞는 데모 결과를 표시한다.
6. 지도 표식과 결과 목록의 선택 상태는 서로 동기화된다. 표식에서 목적지명, 공항 코드, 예시 운임, 항공사와 직항 여부를 확인할 수 있다.
7. 화면은 계속 예시 데이터 · 실시간 아님을 명확히 표시한다. 지도나 노선이 실제 대한항공 운항 현황을 증명하는 것처럼 표현하지 않는다.
8. 지도 타일을 제공하는 OpenStreetMap의 저작자 표시를 유지한다. 타일은 인터넷 연결이 필요하다는 점을 실행 문서에 쓴다. Leaflet 라이브러리는 저장소에 포함하고 라이선스 파일을 함께 둔다.

## 범위 밖

- 실제 운임 API 연결, 항공편 재고 확인, 실제 노선 운항 여부 확인.
- 가격 이력 저장 및 자동 수집.
- 실시간 대한항공 노선 전체를 보장하는 지도.

## 완료 산출물

- 검색 버튼과 지도가 반영된 시제품.
- 목적지 공항 좌표와 지도 사용 안내.
- 실행 방법 및 제한 사항.
- 독립 검토용 전달서와 review_records/KAF-002.md 누적 기록.
