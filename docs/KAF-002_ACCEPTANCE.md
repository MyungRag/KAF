# KAF-002 완료 기준

- 작업 ID: KAF-002
- 완료 기준 버전: 1.0
- 적용 기획서: docs/KAF-002_PLAN.md 버전 1.0
- 대상 저장소: MyungRag/KAF

| ID | 완료 기준 | 확인 방법 |
|---|---|---|
| KAF2-AC-01 | 검색 실행 버튼에 검색이라고 표시된다. | 화면에서 버튼 문구 확인 |
| KAF2-AC-02 | 지도 배경은 지리적으로 알맞은 세계 지도를 표시하고 OpenStreetMap 저작자 표시를 제공한다. | 화면 및 지도 attribution 확인 |
| KAF2-AC-03 | 각 목적지 표식은 해당 결과 IATA 공항 코드에 맞는 공항 위도·경도에 놓인다. | 좌표 데이터와 지도 위치 대조 |
| KAF2-AC-04 | 직항 노선은 검색 결과의 direct 값이 참일 때만 표시한다. 경유 결과를 직항 선으로 표시하지 않는다. | 직항·경유 결과를 각각 확인 |
| KAF2-AC-05 | 검색 결과에서 제외된 목적지는 지도에 나타나지 않는다. | 지역, 항공사, 직항 필터 변경 |
| KAF2-AC-06 | 지도 표식과 결과 목록에서 같은 목적지를 선택하면 선택 상태가 서로 맞고, 표식에서 목적지, IATA 코드, 운임, 항공사, 직항 여부를 확인할 수 있다. | 표식과 목록 양쪽에서 상호작용 |
| KAF2-AC-07 | 작은 화면에서도 지도가 읽을 수 있고 가로 넘침이 없다. | 모바일 뷰 확인 |
| KAF2-AC-08 | 고정 운임과 지도상의 노선이 데모 데이터임을 예시 데이터 · 실시간 아님으로 계속 표시한다. 실제 운항 현황으로 오해시키지 않는다. | 페이지와 지도 문구 확인 |
| KAF2-AC-09 | 실행 문서에 OpenStreetMap 타일에 인터넷 연결이 필요함을 설명하고 Leaflet 라이선스 파일을 포함한다. | README 및 라이선스 파일 확인 |

## 제외 기준

실시간 운임, 실제 대한항공 노선 가용성, 자동 기록, 과거 가격 데이터 연결은 KAF-002 완료 기준에 포함되지 않는다.
