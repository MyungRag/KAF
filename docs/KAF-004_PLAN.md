# KAF-004 개인용 대한항공 운임 관찰 시험

- 작업 ID: `KAF-004`
- 기획서 버전: `1.0`
- 상태: 구현 기준 초안
- 대상 저장소: `MyungRag/KAF`
- 사용자: 저장소 소유자 본인
- 작성일: `2026-11-10`

## 1. 목표

인천(ICN)에서 출발하는 대한항공 직항 여행 가운데 사용자의 날짜 조건에 맞는 왕복 항공권을 찾아, 현재 운임과 이후 변화를 개인 컴퓨터에 기록한다. 먼저 대표 목적지 3곳으로 조회 방법을 검증한 뒤, 문제가 없으면 대한항공 직항 목적지 전체로 넓힌다.

이 도구는 개인의 여행 날짜와 목적지를 고르는 용도다. 공개 배포, 다른 사용자의 예약 중개, 판매·제휴 수익화는 범위에 포함하지 않는다.

## 2. 초기 검색 조건

### 여정

- 출발 공항: 인천국제공항 `ICN`.
- 목적지: 초기 시험은 도쿄 나리타(`NRT`), 싱가포르(`SIN`), 로스앤젤레스(`LAX`) 3곳으로 시작한다. 시험 시점의 대한항공 직항 운항 여부를 다시 확인한다.
- 항공편: 대한항공이 실제 운항하는 직항 왕복편만 포함한다. 공동운항으로 대한항공 편명이 표시되더라도 다른 항공사가 운항하는 편은 별도로 표시하거나 시험 범위에서 제외한다.
- 인원과 좌석: 성인 1명, 일반석.
- 표시 가격: 세금과 유류할증료를 포함한 왕복 총액, KRW.

### 날짜 조합

1. 오늘부터 365일 뒤까지 출발 후보를 만든다. 귀국일은 출발 주의 다음 주말까지 이어질 수 있다. 가격 검색 제공자가 실제 예약 가능한 날짜까지만 운임 조회를 시도하고, 예약 창이 아직 열리지 않은 여정은 `운임 미제공`으로 기록한다.
2. 매주 금요일 또는 토요일에 출발한다.
3. 출발한 주의 다음 주 토요일 또는 일요일에 돌아온다. 따라서 매주 목적지별 기본 후보는 최대 4개다.
4. 사용자가 지정한 특수 연휴 날짜 조합을 최대 5개 더한다. 각 항목에는 출발일, 귀국일, 설명을 저장한다.
5. 여행 중 평일에서 대한민국 공휴일을 뺀 일수를 연차 참고값으로 표시한다. 출국일과 귀국일이 평일이면 하루씩 포함한다.

특수 연휴의 날짜 범위와 별도 연차 한도는 사용자가 정한 값만 사용한다. 임의로 공휴일이나 개인 휴가를 만들어 넣지 않는다.

## 3. 진행 단계

초기 도구는 `tools/kaf004/generate_search_grid.py`, `tools/kaf004/search_amadeus.py`, `tools/kaf004/pilot_routes.json`이다. 첫 도구는 날짜·목적지 검색표를 만든다. 두 번째 도구는 키가 제공된 경우 Amadeus 검색 결과를 화면에만 표시하며 아직 자동으로 가격을 저장하지 않는다.

### 단계 A — 3개 목적지에서 조회 가능성 확인

- 먼저 한 주의 기본 날짜 조합 4개를 3개 목적지에 적용해 최대 12개 여정을 조회한다.
- 반환된 날짜, 대한항공 실제 운항 여부, 직항 구간, 세금 포함 총액, 통화를 대한항공 예약 결과와 대조한다.
- 조회 수단이 반복 검색과 결과 저장을 허용하는지 확인한다.
- 검색 결과가 없거나 예약 창이 열리지 않았으면 빈 결과 상태와 이유를 기록한다. 데모값이나 추정값으로 대체하지 않는다.

### 단계 B — 3개 목적지의 1년 후보 추적

- 3개 목적지 × 주당 최대 4개 조합 × 약 52주로 기본 최대 624개 여정 조건을 생성한다. 특수 연휴 조건은 별도로 더한다.
- 전체를 7개 배치로 나눠 하루 한 번 실행한다. 모든 검색 조건은 대략 주 1회 다시 조회한다.
- 각 조회는 새 관찰 행으로 저장한다. 동일 여정의 기존 가격을 덮어쓰지 않는다.

### 단계 C — 전체 대한항공 직항 목적지로 확대

- 단계 A와 B에서 조회 결과의 정확성, 허용 범위, 실제 호출 한도와 실패율을 확인한 뒤 확대한다.
- 목적지 목록은 대한항공의 공식 운항 노선 정보를 기준으로 갱신한다. 계절 노선은 적용 기간을 기록하고, 더 이상 운항하지 않는 노선은 삭제하지 않고 비활성 상태로 둔다.
- 전체 노선으로 확대하기 전 예상 호출 수를 계산한다. 제공자가 허용하는 호출 수를 확인하지 못하면 무리하게 전체 검색을 실행하지 않는다.

## 4. 운임 데이터 접근 선행 조건

운임 자동 수집은 검색 코드보다 먼저 데이터 접근 경로를 검증한다.

- 대한항공 공식 사이트에서 공개된 사용자 검색 기능으로 가격이 조회되는 것과, 그 결과를 프로그램이 자동으로 반복 수집해 저장해도 되는 것은 별도 조건이다.
- 대한항공의 공개 여객 운임 API와 자동 수집 허용 조건은 현재 확인되지 않았다. 개인용이라는 이유만으로 비공개 API나 자동화 권한을 가정하지 않는다.
- Amadeus Self-Service Flight Offers Search를 첫 API 후보로 시험한다. 공식 FAQ는 독립 개발자도 사용할 수 있고 테스트·프로덕션에 월별 무료 호출량이 있다고 안내한다. 다만 테스트 환경은 실제 전체 운임 데이터가 아니며, American Airlines·Delta·British Airways·저비용 항공사 데이터는 제공하지 않는다고 명시한다. 대한항공(KE) 운임 포함 여부는 공개 FAQ만으로 확정할 수 없으므로 키를 발급받은 뒤 세 목적지에서 직접 확인한다.
- Amadeus의 프로덕션 접근에는 별도 약관이 적용되고 무료 호출량 초과분은 API별로 청구된다. 장기 가격 기록 보관 권한과 허용된 자동 호출 범위도 현재 사용자 약관 또는 Amadeus의 서면 답변으로 확인하기 전에는 확정하지 않는다. 테스트 자격 증명으로 받은 운임을 장기 이력에 저장하지 않는다.
- Skyscanner Live Prices 문서는 자동화된 Live Pricing 요청을 허용하지 않는다고 안내한다. 파트너 승인을 받았더라도 해당 조건을 지키지 않는 자동 수집에는 사용하지 않는다.
- CAPTCHA 우회, 비공개 내부 API 호출, 로그인 보호 우회, 차단 회피는 하지 않는다.
- 허용된 자동 조회 경로가 확인되기 전에는 실제 운임 자동 수집이 완료됐다고 표시하지 않는다. 필요한 경우 단계 A는 사용자가 공식 페이지에서 직접 검색하고 결과를 수동 기록하는 방식으로 제한한다.

## 5. 가격 관찰 기록

가격 기록은 사용자 컴퓨터에만 저장한다. 저장소에 개인 기록을 커밋하거나 공개 배포하지 않는다.

각 관찰 행에 다음 정보를 저장한다.

- 검색 관찰 시각 및 데이터 출처
- 출발·도착 공항, 출국일, 귀국일, 검색 배치
- 인원, 좌석, 통화, 세금 포함 여부
- 대한항공 운항 여부, 항공편 번호, 각 직항 구간
- 왕복 총액, 이용 가능 여부, 검색 실패 또는 미제공 이유
- 원문 재확인 링크 또는 예약 검색으로 이동할 수 있는 링크

최초 실행 이전의 운임 기록은 만들지 않는다. 가격 기록이 쌓이기 전에는 `누적 최저가` 또는 `관측 평균`을 계산하지 않고, 현재 조회된 조건 간 최저가만 보여준다. `최근 1년 최저가`라고 표시하려면 실제로 최근 365일 관찰 기록이 있어야 한다.

## 6. 결과 표시

- 날짜와 목적지 조건이 같은 결과를 현재 총액이 낮은 순으로 정렬한다.
- 항공편이 없거나 가격을 가져오지 못한 경우 가격을 `0원`이나 임의 값으로 표시하지 않는다.
- 각 결과에 마지막으로 성공한 조회 시각을 표시한다. 오래된 값은 최신 가격처럼 보이지 않도록 한다.
- 동일 목적지라도 여행 날짜가 다르면 별도 여정으로 유지하고, 날짜가 다른 운임을 같은 과거 가격 비교 그룹에 섞지 않는다.
- 운임은 조회 시점의 관찰값이다. 구매 단계에서 가격·좌석·운항 여부를 다시 확인하도록 예약 링크를 제공한다.

## 7. 범위 밖

- 공개 웹 배포, 다중 사용자 계정, 예약·결제.
- 허가가 확인되지 않은 웹사이트 스크래핑, 자동 폼 제출 또는 API 호출.
- 과거 1년 운임 복원 및 관측하지 않은 가격 생성.
- SkyTeam 항공사 또는 다른 항공사 운임.
- 특수 연휴 5개 초과 자동 추정.
