# KAF-003 기획서

- 작업 ID: KAF-003
- 기획서 버전: 1.2
- 상태: 제공자·사용 권한 타당성 검토
- 대상 저장소: MyungRag/KAF
- 연결 이슈: [#7](https://github.com/MyungRag/KAF/issues/7)
- 작성일: 2026-11-10

## 1. 목표

대한항공 및 SkyTeam 운임을 사용자 검색 시 조회할 수 있는지, 그리고 일일 가격 관찰값을 장기간 저장해 KAF의 가격 비교에 쓸 수 있는지 확인한다. 실제 API 연결 전에 제공자 승인, 노선별 운임 범위, 자동 검색 허용 여부, 저장·재표시 권한, 비용과 호출 한도를 근거와 함께 결정한다.

이번 작업은 제공자와 사용 조건을 결정하는 **기획·타당성 조사**다. 실제 운임 API 연결, 검색 백엔드, 가격 DB, 스케줄러는 별도 구현 작업으로 남긴다.

## 2. KAF에서 분리해 확인할 검색 방식

1. **사용자가 누르는 실시간 검색**: 출발지, 목적지, 출국일과 귀국일이 정해진 순간에 현재 조회 가능한 여정을 요청한다. 결과에는 제공자와 조회 시각을 표시하고, 예약 전에 가격과 좌석을 다시 확인해야 한다.
2. **매일 정해진 조건을 조회해 이력으로 저장**: 같은 여정 조건을 반복 검색해 날짜별 가격 관찰 기록을 만든다. 사용자 검색과 별도의 자동 호출이므로 제공자의 자동화 허용, 저장·재표시 권한, 호출 비용을 따로 확인한다.

사용자가 매일 직접 누르는 검색과 서버 스케줄러가 매일 자동 실행하는 검색은 호출 주기가 같아도 제공자 규칙상 다른 방식이다. 사용자의 최초 구독 동의만으로 이후 자동 호출이 허용된다고 간주하지 않는다.

KAF의 목적지·날짜 우선 탐색은 정확한 여정이 아직 정해지지 않은 탐색 단계와, 항공권을 확인하는 정확한 검색 단계를 나눠야 한다. 추정 운임을 실시간 확정 운임으로 표시하지 않는다.

## 3. 2026-11-10 공식 문서 조사 결과

### Skyscanner

- API 접근은 Partnerships 팀에 신청한 뒤 검토·승인을 받아야 한다. 승인은 보장되지 않았고 이번 조사에서 신청을 제출하지 않았다. 인증 키는 HTTPS 요청의 `x-api-key` 헤더를 사용하며 브라우저 코드나 공개 저장소에 두면 안 된다.
- Flights Live Prices는 특정 출발지·목적지와 날짜 검색에서 현재 파트너 가격과 예약 가능한 여정을 조회하는 API다. `/create`와 `/poll` 검색 흐름 및 항공사 필터를 제공한다. 다만 해당 검색 필터의 존재가 대한항공 또는 모든 SkyTeam 항공사의 모든 노선·날짜 운임을 보장하지는 않는다. 실제 보유 콘텐츠는 승인된 계정으로 표본 검색해야 한다.
- 이용 지침은 정확한 출발지·목적지·날짜가 정해진 사용자 시작 검색에 Live Pricing을 사용하도록 하고, 사용자 동작 없는 자동 Live Pricing 호출은 하지 않도록 한다. 라이브 검색의 일정 비율이 제휴 예약 링크 클릭으로 이어지는 서비스 전제를 제시한다. KAF의 매일 자동 수집은 현재 공개 지침 그대로는 진행할 수 없다.
- Flights Indicative Prices는 여러 목적지나 날짜를 넓게 탐색하는 데 쓸 수 있지만, 실시간이 아닌 캐시 참고 가격이다. 가격을 몇 일 보관할 수 있다고 설명하므로, KAF가 자체적으로 쌓을 365일 운임 이력을 대신하지 않는다.
- 공개 기술 문서만으로 Live Prices 응답을 장기 보관하고 가격 이력으로 재표시할 권한은 확인하지 못했다. 저장 기간, 사용자 표시, 자동 호출 및 파생 통계 사용을 파트너 담당자에게 서면으로 확인한다.

### Sabre 대체 후보

- Sabre **Low Fare History API**는 특정 도시쌍과 여행일 조합에 대해 현재 날짜와 직전 14일의 조회일별 최저 직항 운임 및 전체 최저 운임을 반환한다고 명시한다. 이 자료는 Sabre 캐시에 있는 검색 운임을 기반으로 하며, 모든 항공사·시장 가격을 빠짐없이 실시간 조회한다는 의미는 아니다.
- 이 API는 별도 활성화와 **Sabre Developer Hub / Travel Insight Engine Amendment** 서명이 필요하다. Sabre 문서는 담당자 또는 계약을 통해 API·환경별 권한을 받도록 안내한다. 따라서 공개 문서에 API가 있다고 바로 실제 키나 상용 호출 권한이 생기는 것은 아니다.
- KAF가 원하는 1년치 이력을 바로 제공하지는 않는다. 단기 14일 추이의 대체 후보로 검토하고, 이후 매일 관측값을 자체 누적할 수 있는지와 데이터 저장·표시 권한을 계약에서 확인한다.
- 실제 대한항공·SkyTeam 노선 및 한국 시장(POS)별 운임 공급 여부는 공개 문서만으로 확인되지 않는다. 승인된 Sabre 계정에서 항공사·노선별 표본을 조회해야 한다.
- 따라서 현재 실행 후보는 (a) Skyscanner에서 사용자가 직접 시작하는 정확한 날짜 검색과, (b) Sabre의 계약형 14일 이력 API를 각각 검토하는 것이다. 무인 일일 수집에는 자동 호출과 가격 보관·재표시를 허용하는 서면 계약이 있는 공급자만 사용한다.

### Skyscanner 운임 제휴 링크 대안

- Skyscanner의 **Affiliates Link API**는 항공권 운임 API가 아니다. 출발지·목적지·날짜 등을 포함한 링크를 만들어 사용자를 Skyscanner의 검색 결과 페이지로 보내는 리디렉션 API다. 제휴 계정의 Impact `mediaPartnerId`가 필요하며, 날짜 검색과 항공사·동맹 필터를 링크에 포함할 수 있다.
- Live Prices API 승인을 받지 못하더라도 제휴 링크 온보딩이 가능하다면 KAF에서 검색 조건을 넘겨 사용자가 Skyscanner 웹사이트에서 실시간 가격을 직접 보게 하는 제품 경로가 될 수 있다. 다만 가격 응답은 KAF로 돌아오지 않으므로 KAF 내부 결과 표시, 가격 저장, 가격 이력 분석은 제공하지 못한다.
- 따라서 링크 방식은 “외부 사이트에서 현재 운임 확인”의 대안으로 평가하고, “KAF가 운임을 받아 일일 기록”하는 요구의 해결책으로 간주하지 않는다. 제휴 링크 및 Impact 계정 자격은 별도로 확인한다.

### 기타 제공자 및 직접 연결

- Duffel은 현재 서비스 계약에서 메타검색 목적의 사용을 제한한다. KAF의 여러 항공사 가격 비교 용도로는 사용하지 않는다. 서비스 계약 예외가 서면 승인될 경우에만 재검토한다.
- 대한항공의 제3자 여객 운임검색용 공개 API 문서와 접근 절차는 이번 공개 문서 조사에서 확인하지 못했다. 공개 문서를 찾지 못했다는 사실만으로 비공개 파트너 API가 없다고 단정하지 않는다.
- GDS, NDC 또는 항공사 직접 연결은 후속 후보군이다. 각 계약에서 반복 조회, 이력 저장, 재표시, 가격 분석 권한을 확인하기 전에는 KAF의 대안으로 확정하지 않는다.

## 4. 조사 범위

1. Skyscanner 파트너 신청 절차, 승인 전·후 접근 범위와 필요한 제품 설명을 확인한다.
2. 승인 계정이 생기면 대한항공 및 SkyTeam 항공사를 구분해 실제 노선·날짜·직항 조건별 콘텐츠를 조회할 검증 절차를 정한다. 항공사 필터만으로 노선 보유를 추정하지 않는다.
3. 사용자 시작 검색과 예약 링크 흐름, 날짜 범위 탐색을 위한 Indicative 결과 사용 조건을 구분한다.
4. 매일 자동 검색이 허용되는 제공자를 찾는다. Skyscanner의 사용자 시작 검색 조건과 Sabre Low Fare History 같은 계약형 대안을 구분하고, 각 제공자의 호출 한도·요금·자동화 허용 범위를 서면 근거로 확인한다. 호출량은 노선 수 × 정확한 여정 조건 수로 산정한다.
5. 실시간 운임 API가 승인되지 않을 때의 Skyscanner 외부 검색 링크 대안을 평가한다. 이 경로가 가격 응답을 KAF로 반환하지 않는다는 제한과 제휴 계정 요구를 명시한다.
6. 가격 응답을 장기 저장하고 KAF에 이력으로 표시할 수 있는지, 허용 저장 기간과 삭제·갱신 규칙을 문서나 서면 답변으로 확인한다.
7. 진행 가능하면 단일 표본 검색 조건과 서버 측 연결·가격 관찰 저장소의 설계안을 제안한다.
8. 근거에 따라 `진행`, `조건부 진행`, `보류` 중 하나로 결론 내고 미확정 조건을 기록한다.

## 5. 표본 검색과 기록 데이터 초안

실제 표본 노선은 승인된 제공자에서 콘텐츠가 확인된 뒤 고른다. 표본은 성인 1명, 왕복, 일반석, KRW, 세금 포함으로 고정하고, 대한항공 필터와 SkyTeam 항공사 필터의 범위·결과를 따로 확인한다. 직항·경유 여부는 항공사 이름이나 지도 선이 아니라 여정 구간(segment)으로 판정한다.

가격 저장이 허용될 때 필요한 필드 후보:

- 검색 관찰 시각(UTC) 및 제공자·요청 식별자
- 출발·도착 공항, 출국·귀국 날짜, 성인 수, 좌석 등급, 직항 조건, 항공사 필터
- 총액, 통화, 세금 포함 여부와 제공자가 응답한 세금·수수료 정보
- 항공사, 마케팅·운항 항공편 번호, 각 여정 구간, 경유 횟수
- 예약 가능 여부, 제공자 예약 링크 또는 재조회 식별자, 오퍼 만료 시각
- 성공·부분 결과·오류 상태와 재시도 정보

필드 보존 여부와 기간은 제공자 이용 조건을 확인한 뒤 결정한다. 동일한 가격 비교 그룹에서는 출발지, 목적지, 여행 날짜와 기간, 인원, 좌석, 직항 조건, 항공사 범위, 통화 및 세금 포함 여부가 일치해야 한다.

## 6. 보안 및 실행 원칙

- 파트너 신청이나 공급자 문의는 이 기획 검토에서 제출하지 않는다. 외부 신청은 계정 담당자와 연락 정보가 필요하며 별도 승인이 있어야 한다.
- API 키는 브라우저·저장소·로그에 넣지 않는다. 향후 구현 시 서버 측 비밀 저장소와 백엔드 제공자 어댑터를 사용한다.
- 자동 호출 및 가격 기록 저장 권한을 확인하지 못하면 해당 기능을 구현하지 않는다.
- 과거 가격은 수집이 시작된 시점부터 쌓인다. 과거 날짜의 값을 실제 관측한 것처럼 만들거나 예시 데이터를 실운임으로 섞지 않는다.
- KAF-002 PR #6은 현재 `main`에 병합되지 않았다. KAF-003 구현은 KAF-002를 기반으로 할 경우 해당 변경이 검토·병합된 기준을 사용하거나 별도 기준 커밋을 명시한다.

## 7. 범위 밖

- 파트너 신청 제출, 이메일·외부 문의 전송.
- 실제 운임 조회, 웹사이트 스크래핑 또는 예약.
- 실제 API 키·계정 연결.
- 사용자 검색 API, 데이터베이스, 자동 스케줄러 구현.
- 승인되지 않은 데이터 저장·재배포·표시.
