## 이 단계에서 완료로 보지 않는 항목

- API 접근이 승인되었다는 확인 없이 실시간 운임 연결이 가능하다고 판정하는 것.
- 매일 자동 호출과 장기 저장 권한을 확인하지 않은 가격 수집.
- 실제 API 키 발급·저장, 실시간 검색, 데이터베이스·스케줄러 구현.
- 샘플·Indicative 운임을 실제 실시간 운임 또는 사용자가 직접 관측한 가격 이력으로 표시하는 것.
- 최초 사용자 동의만을 근거로 무인 일일 호출 권한이 있다고 간주하는 것.
